# Dev Log — 2026-05-19

## Project: Image Compressor

A single-page image compression web app, built from scratch in one session.

**Live deployment**: Zeabur (connected to GitHub repo)
**Repository**: https://github.com/ariachen2020/compress (public)

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router, TypeScript) |

## Features Implemented

### Core
- **Upload** — drag & drop or click, supports JPG/PNG/WebP, max 20MB per file
- **Scale mode** — proportional resize with aspect ratio preserved
- **Crop mode** — interactive crop with aspect ratio lock (16:9, 4:3, 1:1, 3:2, 9:16), then resize
- **Quality slider** — 1–100 with Low/Medium/High labels
- **Size presets** — HD 1920×1080, 1280×720, 800×600, Thumbnail 400×300, Avatar 200×200, Custom
- **Output format** — keep original, or convert to JPEG/PNG/WebP

### File Size Display
- Each image shows a prominent badge: **"1.2 MB → 700 KB (-42%)"**
- Green badge for savings, orange badge if file got larger
- Batch summary in bottom bar: total images compressed + total saved

### Batch Operations
- **Compress All** — concurrent processing (max 3 parallel)
- **Download All as ZIP** — client-side ZIP packaging via JSZip
- **Cancel** — abort in-flight compressions
- **Clear All** — remove all images

### Preview Comparison
- **Slider view** — draggable divider comparing original vs compressed (touch-enabled for mobile)
- **Side-by-side view** — original and compressed displayed next to each other

### Mobile Support
- Responsive layout (sidebar on desktop, stacked on mobile)
- Touch events on comparison slider
- Sticky bottom batch action bar
- Proper bottom padding to avoid content overlap

## Architecture

```
Browser                          Server (Next.js API Route)
──────                          ──────────────────────────
Upload files                    POST /api/compress
  ↓                               ↓
Zustand store                   FormData → sharp pipeline
  ↓                               ↓
Send one image per request      resize / crop / compress
  (max 3 concurrent)              ↓
  ↓                             Binary response + headers
Display compressed preview        X-Original-Size
  + file size comparison          X-Compressed-Size
  ↓                               X-Width / X-Height
Download individual or ZIP
```

- No server storage — images processed in-memory and returned immediately
- ZIP generated client-side from existing Blobs (no re-upload needed)

## Issues Encountered & Resolved

1. **sharp not found at build time** — Was included by Next.js as optional dep but not in node_modules. Fixed by explicitly adding `pnpm add sharp`.
2. **Buffer type incompatible with Response** — TypeScript error with `new Response(buffer)`. Fixed by wrapping with `new Uint8Array(buffer)`.
3. **shadcn/ui Select onValueChange type** — base-ui Select passes `string | null`, not `string`. Added null guards.
4. **Slider onValueChange type** — base-ui Slider returns `number | readonly number[]`. Used `Array.isArray()` check.
5. **Zeabur "no branches found"** — Private repo permissions issue. Resolved by switching to public.
